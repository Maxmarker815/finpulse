# FinPulse — Project Context

> AI-powered personal finance app для СНГ. Lifestyle Mirror — флагманская фича.

## О проекте

**FinPulse** — fintech-приложение для учёта личных финансов с AI-зеркалом образа жизни. Главное отличие от конкурентов: AI смотрит не на цифры, а на паттерны — и даёт лайф-советы, а не просто финансовые.

**Стадия:** прототип готов (лендинг + интерактивный калькулятор). Дальше — MVP-разработка iOS-приложения.

**Целевые рынки:** Россия, Кыргызстан, СНГ. Российский рынок 66 млрд ₽ (Q1 2025, +16% г/г), КР +45% годовых рост digital-платежей.

**Команда:** Maksat (founder, не разработчик). Разработчиков нанимает.

## Бренд и дизайн-система

### Цвета (СТРОГО следовать)
- **Золото:** `#FFB422` (primary), `#FFC547` (bright), `#C97E00` (deep)
- **Графит:** `#09090B` (text/dark blocks), `#52525B` (text-2), `#A1A1AA` (text-3)
- **Жемчужно-белый:** `#FFFFFF` (backgrounds), `#FAFAFA` (surface-2), `#F4F4F5` (surface-3)
- **БЕЗ ЧЁРНОГО** как декоративного цвета фона. Чёрные блоки только для premium-секций (Mirror, Security, CTA).
- Золото — акцент 5% поверхности. Не доминанта.

### Типографика
- **Один шрифт:** Inter (300/400/500/600/700/800)
- НЕТ Playfair Display, НЕТ серифных шрифтов
- Tabular nums везде для цифр (`font-variant-numeric: tabular-nums`)
- Letter-spacing -0.02em для крупных заголовков

### Геометрия
- Скругления: **8-14px** везде. Не 24px.
- Иконки: **тонкие SVG line-style** (1.5-2px stroke), НЕ цветные эмодзи в декоративных плашках
- Эмодзи допустимы только как функциональные обозначения (категории расходов в списках, как в Apple Wallet)

### Стиль-эталоны
Stripe / Mercury / Linear / Vercel / Apple 2026. Холодный минимализм, чистая типографика, premium-feel.

### Антипаттерны (не делать)
- Тёплые жёлто-кремовые tinted фоны (выглядит «египетски/персидски»)
- Золотые круглые «плашки» под каждой иконкой
- Pulsing rings, glow эффекты, декоративные градиенты
- Дешёвые тени в тёплых тонах

## Уникальные фичи продукта

1. **🪞 Lifestyle Mirror** — AI-зеркало жизни через деньги. Анализирует не «куда ушли», а «как ты живёшь». Даёт лайф-советы (зал вместо такси, общение вместо кофеен).
2. **AI-инсайты в Free** — все умные подсказки бесплатно. Никто из конкурентов не делает.
3. **Локальная приватность** — история и AI-переписка на устройстве (iPhone Keychain). На сервер только анонимные паттерны.
4. **Семейный режим в Free** — совместный бюджет на 2 человек бесплатно. Каждому — свой личный AI.
5. **Без рекламы. Никогда.** Даже в free-версии.
6. **Multi-currency для СНГ** — KGS, RUB, KZT, USD, EUR + 30 валют.

## Бизнес-модель

- **Free-план** — все базовые фичи + все AI-инсайты + семья 2 чел + до 5 счетов + 3 цели накоплений
- **Pro: 499 ₽/мес или 3 990 ₽/год** (премиум-позиционирование)
- Pro = безлимиты, семья до 6, продвинутые удобства, регулярные платежи, push в реальном времени
- Lifetime — рассмотрим в будущем

## Технологический стек (план)

### MVP (Q3 2026)
- **iOS первым** — Swift / SwiftUI (нативная производительность для SMS-парсинга)
- **Android вторым** — после iOS, через Kotlin или Flutter (TBD)
- **Backend** — FastAPI (Python) + PostgreSQL + Redis
- **AI** — Claude API для Lifestyle Mirror и категоризации трат
- **Хранение** — локально (Keychain) + опционально iCloud sync под пользовательским ключом
- **Аналитика** — приватная, через Mixpanel или собственная

### Лендинг и калькулятор
- Vanilla HTML/CSS/JavaScript
- Chart.js для графиков
- Inter font (Google Fonts)
- Деплой через Vercel/Netlify

## Принципы работы

1. **Качество > скорость.** Премиум-продукт, не MVP-калоша.
2. **Privacy by default.** Каждое решение проходит фильтр приватности.
3. **Free даёт реальную ценность.** Не урезанная демка — а полный инструмент.
4. **Lifestyle Mirror — главное.** Все остальные фичи — его поддержка.
5. **Согласовывать визуал с фирменным стилем.** Ни одного отступления от палитры.
6. **Русский язык — по умолчанию.** Английский — потом, как expansion.
