## 🎯 Ключевые решения проекта

### Бизнес-модель
- **Freemium** — все AI-фичи бесплатно (Lifestyle Mirror, прогноз, инсайты)
- **Pro: 499 ₽/мес или 3 990 ₽/год** (премиум-позиционирование)
- Pro = безлимиты, семья до 6 человек, продвинутые удобства

### Целевые рынки
- 🇷🇺 Россия (66 млрд ₽ объём сегмента, +16% Q1 2025)
- 🇰🇬 Кыргызстан (45% рост цифровых платежей)
- 🌏 СНГ / Центр. Азия (CAGR 13.7%)

### Уникальные фичи
1. 🪞 **Lifestyle Mirror** — AI-зеркало жизни через деньги
2. 🤖 **Все AI-инсайты в Free** (никто из конкурентов не делает)
3. 🔒 **Локальная приватность** — данные на устройстве
4. 👨‍👩‍👧 **Семейный режим в Free** для двоих
5. 🚫 **Без рекламы. Никогда.** Даже в бесплатной версии

### MVP scope
- База + AI-подсказки (киллер-фича сразу)
- SMS/push-парсинг банков на старте
- iOS первым, Android следом
